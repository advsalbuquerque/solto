# Solto

App de mobilidade, força e definição com o peso do corpo (Albuquerque Advogados / Victor Albuquerque).
Site estático instalável (PWA): `index.html`, `manifest.webmanifest`, `sw.js` e `icons/`.

## Publicar no GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / pasta `/ (root)` → Save.
O endereço fica `https://advsalbuquerque.github.io/solto/`.

## Instalar no iPhone
Abra o endereço no **Safari** → Compartilhar → **Adicionar à Tela de Início**.

## Atualizar
Troque os arquivos e mude a versão em `sw.js` (`const CACHE = "solto-v2-1"`), para o iPhone baixar a versão nova.
